在 VS Code 中运行和打开 Jupyter Notebook（`.ipynb` 文件），只需安装微软官方的 **Python** 和 **Jupyter** 插件即可。 

安装插件与打开文件

- 点击左侧活动栏的 **Extensions（扩展）** 图标（快捷键 `Ctrl+Shift+X`）。
- 搜索并安装 **Jupyter** 插件（安装它会自动关联安装 Python 插件）。
- 双击或右键通过 VS Code 打开你的 `.ipynb` 文件即可直接可视化编辑与运行。 

运行 Notebook

- **选择内核（Kernel）**：打开文件后，点击右上角的 **Select Kernel**，选择你本地的 Python 环境或虚拟环境。
- **运行代码块**：点击代码块左侧的 **播放（Run）** 按钮，或者按快捷键 `Shift+Enter` 运行当前单元格。
